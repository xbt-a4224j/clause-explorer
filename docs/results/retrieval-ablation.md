# Retrieval ablation

Generated by `python -m explorer.evals.retrieval_ablation`, which runs with
`OPENAI_API_KEY` unset — every query is in the committed embedding cache.

- Corpus: **152 matter summaries**
- Eval set: **90 known-item queries** over 30 matters, three phrasings each
- Metric: recall@k and MRR against the single correct matter per query

## What this measures, and what it does not

Known-item retrieval — can the ranker find one specific deal from a description of it?
Relevance is ground truth from the database, not a judgement someone authored, so the
numbers cannot be nudged. It does **not** measure topical similarity ("deals like this
one"), which would need relevance judgements this corpus does not carry. Comparable-deal
ranking (#18) is the topical case and is not evaluated by this table.

## Results

| method | recall@1 | recall@5 | recall@10 | MRR |
|---|---|---|---|---|
| pure BM25 | 0.711 | 0.822 | 0.911 | 0.769 |
| hybrid alpha=0.3 | 0.722 | 0.856 | 0.911 | 0.775 |
| hybrid alpha=0.5 | 0.744 | 0.856 | 0.900 | 0.785 |
| hybrid alpha=0.7 | 0.733 | 0.833 | 0.889 | 0.767 |
| pure vector | 0.722 | 0.778 | 0.811 | 0.744 |

**Hybrid wins.** Best is hybrid alpha=0.5 at MRR 0.785, against 0.744 for pure vector and 0.769 for pure BM25.

## By query phrasing

The three phrasings differ in how much wording they share with the indexed summary,
which is exactly what separates the two methods: `parties` repeats the company names
verbatim, `paraphrase` avoids them.

## Read the aggregate table with this caveat

**2 of 3 phrasings are saturated** — every method scores 1.000 recall@1 on `paraphrase`, `parties`, because those queries name the parties and the indexed summary contains those names verbatim. Finding them is not a hard retrieval task for anything.

So the aggregate MRR is dominated by a task nothing can fail, and the differences between methods there are noise. **The discriminating row is `industry_year`**, where the query shares no proper nouns with the target summary. That is where the ranking choice actually shows, and it is the row to look at when deciding whether hybrid earns its place.

Making the eval harder — queries that describe a deal without naming it — needs topical relevance judgements this corpus does not carry. Stated rather than worked around.
